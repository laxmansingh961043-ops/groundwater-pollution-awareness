# AquaTruth – Groundwater & Human Health

An environmental awareness website focused on groundwater pollution, its causes, health impacts, statistics, and preventive solutions.

## 🌊 Features

- Groundwater pollution awareness
- Causes and sources of groundwater contamination
- Health impacts of polluted groundwater
- Statistics and environmental information
- Preventive solutions and awareness tips
- Responsive and modern UI
- Full-screen video section
- Smooth scrolling and animations
- Interactive content sections

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
